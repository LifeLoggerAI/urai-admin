# Privacy Governance Version

This repository adopts `LifeLoggerAI/urai-privacy` version `0.1.0-draft`.

`urai-admin` is treated as high-risk because it can expose privileged user-data access, access-request decisions, audit logs, support workflows, and incident response controls.

Before launch or deployment, this repo must keep a current privacy data inventory, feature manifests, and passing privacy adoption validation.
