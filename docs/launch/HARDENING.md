# URAI Admin Hardening

Domain: uraiadmin.com

Before approval:

- Root and login show only an authorized access gate.
- Global metadata is noindex, nofollow, and noarchive.
- Dashboard, users, leads, content, systems, audit, privacy requests, launch locks, and settings are gated.
- No private data renders before auth completes.
- Admin, ops, and security roles are implemented or documented.
- Sensitive actions have audit logging or an audit plan.
- Private interiors do not show a public ecosystem footer.
- No secrets exist in the client bundle.
- Build, typecheck, tests, and QA are recorded.
- DNS, SSL, deploy URL, latest commit, and owner approval are recorded.
